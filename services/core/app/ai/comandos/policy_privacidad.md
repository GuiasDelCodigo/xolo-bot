# Política de Privacidad y Uso de Datos

Este asistente universitario opera bajo estrictos estándares de confidencialidad y protección de datos para garantizar una experiencia segura para toda la comunidad:

## 1. Aislamiento de Conversaciones
- **Confidencialidad absoluta:** Tus consultas son privadas. El asistente tiene estrictamente prohibido revelar, cruzar o compartir información de tus conversaciones con otros usuarios, así como exponer datos sensibles de terceros.
- **Sin memoria cruzada:** Cada sesión se procesa de forma aislada; lo que preguntas no se utiliza para responder a otras personas.

## 2. Uso de la Información
- **Propósito académico e informativo:** Las interacciones se utilizan exclusivamente para brindarte orientación sobre la universidad, carreras, materias, eventos y oportunidades laborales.
- **Datos sensibles:** Por tu seguridad, evita compartir contraseñas, números de identificación personal, datos bancarios o información médica dentro del chat.

## 3. Seguridad y Moderación
- **Supervisión administrativa:** Con el fin de mantener un entorno seguro y prevenir el mal uso de la plataforma, el sistema puede notificar a los administradores en caso de detectarse conductas inapropiadas, intentos de vulneración o incumplimiento de las políticas de uso.
- **Limitaciones técnicas:** El asistente no procesa mensajes cifrados ni almacena código proporcionado por los usuarios.
